IMG

사람들에게 즐거움을 전달하고 싶은 개발자입니다.

아이디어를 실제로 구현하고, 끊임없이 성장하는 과정 자체를 즐기고 있습니다.

그저 게임을 플레이하던 한 명의 유저에서 시작해 직접 콘텐츠를 만들고 싶다는 목표를 가지게 되었고, 간단한 시스템 제작을 통해 개발의 재미를 깨달았습니다. 이후 C언어와 Unity를 배우며 프로젝트와 대회, 협업을 통해 더 나은 결과를 만들어가는 과정을 배웠습니다.

저는 단순히 게임을 만드는 것을 넘어, 사람들에게 기억에 남는 경험을 제공하는 개발자로 성장하고자 합니다.

SKILLS

  • C++

    STL 기반 알고리즘 문제 해결 능력과 포인터, 메모리 관리 및 객체지향 설계에 대한 이해를 갖추고 있습니다. 데이터 입출력 처리와 시간 복잡도를 고려한 효율적인 코드 작성이 가능합니다.

  • Unity

    상속, 인터페이스, 클래스 구조에 대한 이해를 바탕으로 객체지향 프로그래밍을 활용할 수 있으며, Unity에서 제공하는 다양한 API를 활용해 게임을 개발할 수 있습니다.

  • Unreal Engine

    블루프린트를 활용한 콘텐츠 제작이 가능하며, C++을 활용한 게임 개발 경험이 있습니다.

  • Web

    HTML, CSS, JavaScript를 활용해 웹페이지 개발이 가능하며, SQL 연동 및 개인 웹페이지 서버를 구축 해본 경험이 있습니다.

  • Github

    Commit, Push, Branch 개념을 이해하고 프로젝트를 효율적으로 관리하였으며, Pull Request와 Merge 과정을 통해 협업 및 코드 리뷰를 수행한 경험이 있습니다.

  • Python

    기본 문법과 모듈 활용에 익숙하며, 포켓몬 API 기반의 포켓몬 맞추기 AI와 색상 추론 AI를 개발한 경험이 있습니다.
